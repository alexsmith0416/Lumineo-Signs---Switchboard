01Introduction

The Lumineo Sign Builder is where every sign on a job gets spec'd — step by step, from the first conversation on the opportunity to everything the shop needs before the order is released on the job.

You pick a sign's category and answer the questions as they appear. The Sign Builder picks the exact sign type from your first answers, only asks what applies, and writes the job's Production Description and Field Description for you in the shop's job-ticket format.

Only the questions that apply

Each answer brings up the next questions — nothing that doesn't fit the sign.

Descriptions write themselves

Production and Field Descriptions, built from the answers, ready for the BC job.

A code for every sign

The Spec Code sums up how a sign is built — find signs built the same way on past jobs.

Opportunity to job

Sales answers the core questions; the PM, artist or estimator finishes the job details.

Who this guide is for Sales, project managers, artists, estimators and operations — anyone who specs signs or reads the descriptions. See Roles & Permissions for what your login can do.

02Getting Started

  1. Open the Sign Builder — from its link, the Switchboard app launcher, or a job/opportunity link (it opens that spec directly).
  2. Start a spec — Dashboard → + New Spec (or Builder → + New). Fill in the customer and, if you have them, the opportunity or job number.
  3. Add a sign — under Signs click + Add sign and pick its category (Channel Letters, Wall Cabinet, Monument…).
  4. Answer the questions — the highlighted card is the next one. Answer it and the page moves on.
  5. Preview the descriptions — Preview Descriptions shows the Production and Field Descriptions.
Try it safely first Help → ▶ Launch demo & tutorial opens a practice copy with sample specs and a guided tour. Nothing you do there is saved.

03Dashboard Overview

The Dashboard opens with + New Spec and a link to the Sign Library, then four totals: Signs Built, Specs, Total Units and Approved. Below them, your Recent Specs (with how complete each one is and its status) and your Projects. Click any spec to open it in the Builder.

The sidebar switches between Dashboard, Builder, Projects and Sign Library; Setup (admins) and Help sit at the bottom with the light/dark switch.

05Features & How to Use Them

5.1 Specs

A spec holds every sign of one opportunity or job. Its header has the description, customer, contact, opportunity and job numbers, design reference and project. The bar at the top right shows how complete the whole spec is; open site surveys are counted next to it.

Opportunity details / Job details — Opportunity details asks only the core questions sales needs (category, type, size, colors, install basics…). Job details asks everything the shop needs before the order is released. Switch any time; answers are kept. Specs started on a job open at Job details.

5.2 Signs and categories

Each sign is a card under Signs showing its name, quantity, type, how complete it is and its Spec Code. + Add sign asks for the category; the sign then starts with Quantity and a few first questions (for example Lighted? and New cabinet or new faces?). Those answers pick the exact sign type behind the scenes — the type shows on the card once they're answered.

On the selected sign you can name it (used as its heading when a job has several signs), change the quantity, Copy Sign (handy for another size of the same sign), Refresh it to the latest questions, or delete it.

5.3 Answering questions

  • Choices — click an answer. Long lists show as a drop-down. Some questions also take a typed answer (Other…).
  • Sizes — fill in feet and inches for each part (Height, Width, Depth). It saves once every part is filled.
  • Text and numbers — type and press Enter, or click away.
  • Vinyl colors — Pick colors opens the 3M color list; search and tick every color needed.

After each answer the page scrolls to the next question, and any question your answer brought up is tagged new. If a change means an earlier answer no longer applies, it's cleared and a note tells you what was cleared. Tick Only open questions to hide the answered ones.

5.4 Needs Survey and Open for design

Some questions offer Needs Survey (wall type, electrical…) or Open for design (reveals…). Use them when the real answer isn't known yet. They print at the top of the descriptions as *** SURVEY NEEDED: … *** / *** OPEN FOR DESIGN: … *** until the real answer is filled in.

5.5 Descriptions

Preview Descriptions shows the Production Description (section by section: SIGN OVERVIEW, ROUTING, FABRICATION, PAINT, VINYL & GRAPHICS, ASSEMBLY…) and the Field Description (install sentences). With several signs each gets a SIGN n OF m heading. Job Detail Notes (under the questions) print at the end of the Production Description. Copy text copies the description shown. Tick Part #s to print the BC part number after each linked material — e.g. 2”x2”x.187” Aluminum Angle (#20050) (it starts the way Setup → Materials & Items is set).

5.6 Spec reference page

The panel on the right shows the Sign Specification Reference page that matches the sign once its type is known. Click it (or View Full Size) to see the whole page full screen — Zoom in, Print (one letter page) or Download it. SharePoint opens the reference folder.

5.7 Status and approval

A spec starts as Draft. Submit sends it for review; Operations can Approve it, then Mark Built when the signs are done.

5.8 Print Spec

Print Spec prints a spec sheet: the header, every sign's answers and both descriptions.

5.9 Projects

Group specs that belong together — a multi-site rollout or a campus. Create a project under Projects, then pick it in a spec's Project field. The project shows its specs, signs and total units.

5.10 Sign Library

Every sign ever spec'd. Type the start of a Spec Code (e.g. WC-IL), pick a category or search by customer, sign name, spec or job number. Same code finds signs built exactly the same way; Same type finds the same category and type. Click a row to open its spec.

5.11 Setup (admins)

Setup has these tabs. Most changes save as soon as you make them (text boxes save when you click out of them); ↶ Undo at the top right steps back through this session's changes one at a time (hover it to see what it will undo).

  • Overview — what's in the setup, and the one-time Import from Business Central (exit the demo first — the import isn't available in the sandbox).
  • Categories — what people pick first when they add a sign (Channel Letters, Monument…), in the order they're offered; ↑ ↓ reorders them. Click one to change its name, its Spec Code prefix (the first part of every Spec Code in it — changing it changes the code of signs already spec'd the next time they're opened) and whether it's Active. + Add makes a new category (it starts inactive); + New sign type… creates a sign type in it as a copy of any existing one — questions, answers, rules and descriptions — and opens it on Sign Types to finish. Delete works only on a category with no sign types (move or deactivate them first).
  • Sign Types — pick a category, then a sign type. Edit its description, the name printed in the descriptions ({TYPE}), its Spec Code segment, sort order and whether it's Active. Selected when shows the category's first questions (e.g. Lighted?, New cabinet or new faces?) with their answers as buttons — click the answers that pick this sign type (two answers on one question = either one). The Check box underneath updates as you click, so a clash with another sign type shows before you save. Duplicate copies a sign type with all its questions, answers, rules and Field Description lines; the copy starts inactive with no Selected When.
  • Questions — a sign type's questions by section, in order. Under each: its code and when it's asked, in plain words (When Pan depth is answered — and Custom / irregular shape? is No). Tags: if = only asked when a rule shows it, default = an earlier answer sets its default. Click a question to edit it:
    • Details — the wording, the label printed in the Production Description, section, order, answer type, when it's asked, its default, and its production line format (%1 = the answer, %2 = the label) and the note printed under it.
    • Answers — reorder (↑ ↓), rename, add or remove answers. Prints as changes how an answer reads in the descriptions without changing what people pick; Own line gives an answer its own Production line; BC item links it to its part. Renaming an answer renames it in that sign type's rules and defaults too.
    • Rules — Shown when (which earlier answers bring the question up), Answers offered (limit the answers by an earlier answer) and Defaults (the answer it starts with, by an earlier answer — e.g. Pan depth 2” → Face frame 2”x2”x.187”; people can still pick something else).
    + Add question adds one after the selected question; Delete removes it with its rules.
  • Rules — pick a sign type and a question. Shown when is a grid of its answers × the later questions: tick a box to ask that question for that answer. Defaults picks a later question and sets what it starts as for each answer — for example Face material → Face frame material. Copy these defaults to other sign types… copies the whole set to the other sign types that have both questions.
  • Descriptions — the sentences a sign type's Field Description is built from, in order. Each line shows when it prints (Always, or When “Installed by” is not Customer) and its sentence, with the answer boxes shown as chips named after their question. Click a line to edit it:
    • Sentence — type the wording; Insert an answer at the cursor… drops in a box for any question's answer (tick in lower case for answers mid-sentence) or the quantity, sign type name, sign name, design reference or job no. A sentence whose box comes out blank is left out. starts a new line.
    • Print only when — pick a question, then is answered, is or is not and tick the answers. …and when adds a second condition.
    • Start a new paragraph, ↑ ↓ to reorder, + Add line below and Delete line.
    A line that uses a question the sign type doesn't have is marked in amber with Use instead: a similar question to switch to, any other question, or Delete the line. The Preview on the right builds the description for a sample sign (each question's default or first answer; typed answers show as [Label]); change the answers under Try other answers to check each line — lines left out for the sample are tagged not printed. Copy from another sign type… replaces the lines with another sign type's (Undo puts them back).
  • Check Setup — every problem in the setup, by category and sign type, with what to do about it. Problems stop something working (a sign type nobody can pick, a question that's never asked); Warnings are worth a look (a Field Description line that gets skipped). The red number on the tab is the problem count. Open sign type / Open category jump to it to fix it; Open its descriptions jumps to the Descriptions tab for description warnings.
  • Versions — saved copies of the whole setup that last after you close the app (Undo only covers this session). Give one a name and an optional note and click Save version — do it before a big change. One is also saved automatically before an import from Business Central and before a restore. Changes since lists what's different now, sign type by sign type (questions, answers, rules, defaults, descriptions…). Restore puts the setup back the way it was in that version (Undo can step back, and the setup you had is saved as a version first). Specs aren't changed — their signs pick up the restored questions the next time they're opened. Delete removes a saved version.
  • Materials & Items — links each material answer to its BC item (Item List). The same wording is the same part, so one link covers every sign type that uses it. Pick one rows have several equally good items (sheet sizes, or an angle whose answer doesn't give the wall thickness) — choose from the list. Show part numbers in the descriptions turns the (#20050) part numbers on for everyone. BC items no answer offers yet lists items of the kinds of material the answers use; Add as answer… words it like the existing answers (edit it if you like) and adds it, linked, to the questions you tick.

Still to come: Show Path / Test Category, Question Blocks, Copy/Paste and the rest — see What's New.

06Step-by-Step Walkthroughs

Spec a lighted wall cabinet

  1. Open or start the spec and click + Add sign → Wall Cabinet.
  2. Check Quantity, answer Lighted? → Yes and New cabinet or new faces? → New cabinet. The card now says Wall Sign Cabinet – Lighted.
  3. Answer the highlighted questions: sides, cabinet size (feet and inches), face type, mounting…
  4. Not sure of the wall yet? Answer Needs Survey — it'll show under SURVEY NEEDED until you fill it in.
  5. Click Preview Descriptions to check the Production and Field Descriptions.

Finish an opportunity spec on the job

  1. Open the spec (from the job, or the Builder's Recent Specs).
  2. Switch to Job details — the remaining job questions appear.
  3. Answer them until each sign's bar reaches 100% and replace any Needs Survey / Open for design answers.
  4. Submit for approval.

Find a similar sign from a past job

  1. Note the sign's Spec Code (top right of the Builder).
  2. Open the Sign Library and type the code — or click Same code / Same type on a row.
  3. Click a result to open that spec.

08Shortcuts & Efficiency Tips

  • Enter saves a typed answer and moves on.
  • Esc closes a pop-up or the full-screen reference page.
  • Copy Sign for a second size of the same sign — then change only the size.
  • Click the full-screen reference page to zoom in and out.

09Best Practices

  • Give each sign a name when a job has more than one — it heads its block in the descriptions.
  • Use Needs Survey instead of guessing — it reminds everyone what the survey must confirm.
  • Keep the opportunity spec short; finish the details on the job.
  • Put job-wide notes in Job Detail Notes, not in a sign's answers.

11FAQs & Tips

Do I have to answer everything on the opportunity?

No — Opportunity details only asks the core questions. The rest is finished on the job.

What happens to my answers if I switch the detail level?

Nothing — they're kept; questions outside the level are just hidden.

Why did the type change when I changed “Lighted?”

The first questions pick the sign type. Your other answers carry over where the new type asks the same question.
