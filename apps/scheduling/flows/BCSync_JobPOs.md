# BCSync_JobPOs — purchase orders in the job panel

**What it does.** Every night it copies each open job's purchase orders from BC
into `crfdf_jobpo`, so the job panel's **▸ Purchase orders** section can list
them: PO # (opens it in BC), vendor, date ordered, and BC's status while the
order is open (archived orders show "Closed").

Source: generated by `_gen_jobpos_flow.py` → `BCSync_JobPOs-clientdata.json`;
packaged by `_build_jobpos_solution.py` → `Downloads\BCJobPOs_1_0_0_2.zip`
(solution **BCJobPOs**). Edit the generator, never the JSON. Table:
`scripts/create-jobpo-table.ps1`. App: `services/job-pos.ts`,
`hooks/useJobPOs.ts`, `PurchaseOrders` in `components/JobInfoSections.tsx`.

## Where the POs come from (BC)

Two **API queries** in `bc/lumineo-planning-ext` (v1.0.0.8+), under
`api/lumineo/planning/v1.0/companies(<id>)/`:

| Entity set | Query | What |
|---|---|---|
| `jobPurchaseOrders` | 58401 Lumineo Job POs | open orders — Purchase Line with a Job No., one row per (job, PO), header vendor / order date / status |
| `jobPurchaseOrderArchives` | 58402 Lumineo Job PO Archive | archived orders — fully received / invoiced (BC deletes the order and keeps the archive), plus printed / released versions |

- They're API queries because the first try (v1.0.0.6/7, `QueryType = Normal` +
  Web Services rows `LumineoJobPOs` / `LumineoJobPOArchive`) was **never exposed
  over OData** — 404 for every login, admin included, with the rows Published
  and an OData V4 URL showing. API queries need no Web Services row.
- The flow's app user ("PowerApps Permissions") gets Execute on them through
  `LUM JOB PO READ` (v1.0.0.7), a permission set **extension** of
  `D365 BUS FULL ACCESS`, which it already holds. `LUM PLANNING WB` also grants
  it, but BC wouldn't let the app user assign that to itself (*"SECURITY only
  grants rights to manage permission sets that are also assigned to your
  account"*). Remove the extension once `LUM PLANNING WB` is on the app card.
- UAT, Oct 4 2026: 139 open rows (124 jobs); 9,357 archive rows (6,211 jobs,
  back to 2022) — one page, no `@odata.nextLink`.

## How it works (nightly 5:15 AM Central, or Run)

1. **Get_Open_POs** / **Get_Archived_POs** — HTTP GET on the two entity sets,
   app-registration auth (same as BCSync_NewOrders). **Check_Single_Page** fails
   the run if BC ever pages the answer, rather than syncing half and deleting
   the rest.
2. **Wanted_Rows** — both lists mapped to one shape and kept only for jobs in
   `crfdf_bcjobs` (the open BC jobs on the Jobs list). Key = `<job>|<PO>`.
3. A PO can come back more than once — open **and** archived (20 in UAT), or
   archived under two versions whose vendor / order date differ (42 in UAT).
   Each row carries a rank (open = 1,000,000, archived = its version no.) and
   **Winner** = the highest rank for the key.
4. **Changed_Rows** — wanted rows whose signature (key + vendor no + vendor name
   + order date + status) isn't already in the table. Per changed key (10 at a
   time): create, or update if the saved row differs from the winner. A losing
   duplicate is checked and skipped, so it costs no write.
5. **Stale_Rows** — saved rows whose key isn't wanted any more (job closed or
   left `crfdf_bcjobs`, PO moved off the job) are deleted. Skipped when the
   wanted list is empty (a bad read, not "every PO is gone").

The big lists are compared as `^`-delimited strings (one substring search per
row) instead of `contains()` on arrays, so ~10k rows stay quick. After the first
run a night costs a handful of writes.

## Import & test

1. Run `scripts/create-jobpo-table.ps1` (creates `crfdf_jobpo`).
2. Power Apps → Solutions → Import `BCJobPOs_1_0_0_2.zip`; bind **Microsoft
   Dataverse** to the existing connection. It imports **Off**.
3. If the zip was built without `BC_CLIENT_SECRET`, open the flow → Parameters →
   fill `Bc_ClientSecret`.
4. Turn it on → **Run**. The first run creates every open job's POs (a few
   thousand rows, several minutes). A second run should write nothing.
5. In the app open a job card → ▸ Purchase orders. J29295 (UAT): 20493 Gemini
   (Closed), 19869 Benchmark Foam (Open), 19354 Sullaway Engineering (Closed).
